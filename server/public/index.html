Meeting Copilot: local audio test

Use this page to test real tab-audio capture without joining a meeting. The extension treats this page (/test/ on your local server) as a supported tab.

1. Choose a speech recording

Pick any audio file with spoken questions (for example, record yourself asking "What is the difference between a process and a thread?").

2. Start capture

With this tab active, click the Meeting Copilot toolbar icon and press Start listening, then play the audio above. You should keep hearing the audio (the extension plays captured audio back to you), and the transcript should appear in the assistant window. This requires DEEPGRAM_API_KEY on the server.

Optional: tone check

Plays a 440 Hz tone for 2 seconds to confirm audio is still audible while captured (a tone will not produce a transcript).
